# Web pública de Fotos Jefferson

Sitio de catálogo y pedidos (Nauta e Iquitos). Es independiente del panel `/panel`.

- `npm install` y `npm run dev` para trabajar.
- `npm run build` genera `dist/index.html` (un solo archivo).
- En Vercel es un proyecto aparte con *Root Directory* = `web-publica`.

Los números de WhatsApp de cada sede están en `src/App.jsx` (constante `SEDES`); hoy son de ejemplo.
